# Linguista 阅读工作台

Linguista 的 DeepSeek Harness 插件，当前版本 **0.6.4**。打开 **Linguista**，用右上角在首页与 RSS 之间切换。首页展示 Workshop 软件，切换底栏时，左侧同步显示站点形象与栏目。搜索可检索各站 RSS 的标题与摘要。点击右上角 **Rosetta 石碑** 展开阅读侧栏，集中使用搜索、订阅、伴读与设置，偏好保存在本地。

[网站](https://linguista.cn/home/) · [下载插件](https://github.com/Linguage/home/releases)

## 安装

在 DeepSeek Harness 0.2 系列的插件管理中选择添加插件，在「包名或地址」填入 `https://github.com/Linguage/home`。安装并启用后，从左侧打开 **Linguista**。宿主需要 Node.js 22.19 或以上。

也可以从[发行页](https://github.com/Linguage/home/releases)下载对应版本的 `.tgz` 安装包，在同一个字段中填入文件的本地绝对路径。

## 开始阅读

在 DeepSeek Harness 聊天顶部点击 **在侧栏打开 Linguista**，或从右侧栏的新标签页选择 **Linguista**，即可边聊边浏览首页、RSS 和原站网页，也可以使用独立的 AI 伴读。收起侧栏、切换标签或聊天时保留当前浏览页面。侧栏需要宿主提供原生右侧标签页接口（已核对 0.2.2-rc.1 / rc.2）；较早宿主保留独立主视图入口。

1. 点击右上角 **RSS**，再从底栏选择站点。
2. 点击文章查看摘要。打开即标记为已读，可在筛选菜单找回。
3. 点击 **在原站打开**，默认在插件内查看源页面。顶部可返回阅读、前进后退、刷新或改用系统浏览器。手机端关闭阅读卡片后回到列表。

先打开 RSS 摘要，再点击 **全文阅读** 读取公开正文。Library 显示订阅指向的译文或频道概要。Notion 只读取两个公开订阅中的可匿名访问页面。正文读取失败时保留摘要，可以重试。

桌面版使用宿主原生网页容器，原站登录与网页内容保留在隔离的浏览环境；普通 Web 宿主使用内嵌网页，原站禁止内嵌时可改用系统浏览器。网页与 RSS 正文使用同一预览区域，宽窗左侧文章列表保持可用；RSS 正文采用半透明玻璃背景。关闭网页返回后保留原来的文章、伴读会话和草稿。

点击 **Rosetta 石碑**，首页默认显示八路 RSS 订阅；每路以两行显示名称、简介与简短域名，点击重叠方框图标复制完整订阅链接。侧栏内可切换 **搜索 / 订阅 / 伴读**。搜索使用现有 RSS 标题与摘要缓存，可选择所有订阅或当前站点，搜索结果可以直接进入文章；在工作台按 `/` 可直接打开搜索。

阅读 RSS 文章或原站网页时点击石碑，默认打开当前内容的伴读。顶栏、底栏始终保留；侧栏和内置浏览器仅占两栏之间的区域，窄窗关闭侧栏即可回到网页。可使用提炼要点、解释选段或拆解论证；资料注明来源与版本，输入由用户发送。同一文章地址的摘要、全文和网页使用同一会话，保留最近的未发送草稿。普通 Web 宿主无法读取跨域网页正文时，会明确标记“仅网页地址”。

在石碑侧栏点击 **设置图标**，使用胶囊切换自动 / 浅色 / 深色主题，以及内置 / 系统浏览器；下方可以开关 AI 伴读与 DSH 聊天侧栏集成。关闭侧栏集成会收起已有 Linguista 标签，独立主视图仍可使用。

Notion 入口可以在 Linguista 和 Bullets 两路公开摘要之间切换。只改 Notion 页面时，需要等主站重新发布 RSS 后才能在插件里刷新。订阅失败时，已有缓存仍可阅读。

网站的石碑侧栏只保留搜索与订阅；AI 伴读、设置与内置浏览器在插件中使用。窄窗顶部显示当前站名，默认为 Linguista；点击 Linguista 可在主视图打开 Newsletter 封面。选中站点后模块栏保持展示，彩色图标靠左排列，选中项使用短线标记。

在底栏或模块栏左右滑动可切换相邻项；抓住当前选中图标拖向目标图标，松手选中对应项，玻璃高光跟随手势移动。主视图的软件进度滑块可在拖动中实时切换卡片。宽窗模块入口为两列两行，显示名称与简短说明，超过四项用底部箭头翻页。
